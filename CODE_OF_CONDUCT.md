# Code of Conduct

Kirana welcomes contributors with different backgrounds and experience levels. We want project spaces to be respectful, useful, and safe for everyone.

## Expected behavior

- Be considerate and constructive in issues, pull requests, reviews, and discussions.
- Focus feedback on the work and explain suggestions clearly.
- Respect differing viewpoints and experience levels.
- Help keep discussions on topic and make room for others to participate.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, sexualized language or attention, deliberate intimidation, and publishing someone else's private information without permission are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainers through a private GitHub contact channel, if available. If no private channel is available, contact a maintainer directly through a private channel rather than posting sensitive details publicly. Include links and context that help them assess the report. Maintainers will review reports discreetly, may request more information, and may remove content or restrict participation when needed. They will avoid sharing identifying details beyond what is needed to resolve the concern.

This code applies to project spaces and to public conduct that directly affects the project community.
